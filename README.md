# Datamatrix Notepad

Простая локальная утилита для чтения DataMatrix-кодов со сканера, работающего как COM-порт. Приложение запускается в desktop Chrome или Edge, получает данные через Web Serial, сохраняет заметки в браузере и экспортирует их в UTF-8 `.txt`.

Данные не отправляются на сервер. Заметки, выбранная заметка и настройки сканера находятся только в `localStorage` текущего браузера и профиля.

## Требования

- Windows 10 или 11.
- Desktop Google Chrome или Microsoft Edge с поддержкой Web Serial.
- HTTPS при размещении в интернете или `localhost` при локальном запуске.
- Сканер, настроенный как последовательный порт. Параметры по умолчанию: `9600 baud`, `8 data bits`, `no parity`, `1 stop bit`, `no flow control`, UTF-8, пустой префикс, суффикс CRLF. Для сканеров с нулевым байтом перед каждым знаком можно выбрать UTF-16BE.

Firefox, Safari и мобильные браузеры в MVP не поддерживаются.

## Быстрый старт для пользователя

1. Откройте «Настройки сканера».
2. Проверьте параметры соединения и кодировку. Для стандартной конфигурации оставьте UTF-8; если COM-поток имеет вид `00 30 00 31`, выберите UTF-16BE.
3. Для управляющих символов в префиксе и суффиксе используйте `\r`, `\n`, `\t` и `\\`. Суффикс не может быть пустым.
4. Нажмите «Выбрать и подключить порт» и выберите сканер в системном диалоге браузера.
5. Отсканируйте тестовый код. В диагностическом логе должны появиться сырые данные и завершённый код; CRLF отображается как `\r\n`.
6. Вернитесь к заметкам, создайте заметку и сканируйте коды. Каждый завершённый код добавляется отдельной строкой.

Браузер не предоставляет приложению надёжное имя вроде `COM4`. Поэтому сохраняются пользовательский псевдоним и доступные VID/PID. Если ранее разрешённый порт нельзя определить однозначно, системный диалог нужно открыть повторно.

## Заметки и экспорт

- Создание заметки сохраняется немедленно.
- Название, содержимое, активная заметка и настройки сохраняются автоматически с debounce 300 мс.
- Удаление возможно только вручную и после подтверждения.
- Кнопка «Скачать» создаёт `text/plain;charset=utf-8` файл с содержимым заметки.
- Имя файла имеет вид `{Часть1};{Часть2}.txt`.
  - `Часть1` — шесть цифр из первого точного `00ЦБ-123456`.
  - `Часть2` — первая реальная календарная дата в точном формате `dd.MM.yyyy`.
  - Если часть не найдена, она остаётся пустой, например `;.txt`.

Очистка данных сайта, другой профиль браузера или другой компьютер не содержат прежних заметок. Синхронизации и серверной резервной копии нет.

## Локальный запуск

Требуется .NET 10 SDK.

```powershell
dotnet restore ".\Datamatrix Notepad.slnx"
dotnet run --project ".\Datamatrix Notepad\Datamatrix Notepad.csproj"
```

Откройте адрес `localhost`, показанный командой. Web Serial работает на `localhost` как в secure context.

## Проверка

```powershell
dotnet format ".\Datamatrix Notepad.slnx" --verify-no-changes
dotnet test ".\Datamatrix Notepad.slnx" --configuration Release
dotnet build ".\Datamatrix Notepad.slnx" --configuration Release
dotnet publish ".\Datamatrix Notepad\Datamatrix Notepad.csproj" `
  --configuration Release `
  --output ".\artifacts\publish"
```

Автоматические тесты не заменяют проверку Web Serial с реальным устройством. Перед публикацией заполните [ручной чек-лист](docs/manual-test-checklist.md).

## GitHub Pages

Workflow [deploy-pages.yml](.github/workflows/deploy-pages.yml):

1. восстанавливает зависимости;
2. проверяет форматирование;
3. запускает Release-тесты;
4. публикует Blazor WebAssembly;
5. вычисляет base path из имени репозитория;
6. создаёт `404.html` для прямого открытия SPA-маршрутов и `.nojekyll` для `_framework`;
7. загружает Pages-артефакт и разворачивает его только после успешных quality gates.

Перед первым запуском workflow в настройках репозитория выберите **Settings → Pages → Source → GitHub Actions**. Push и deploy из этой рабочей копии автоматически не выполняются.

Для отката верните предыдущий проверенный коммит и повторно запустите workflow либо повторно разверните артефакт предыдущего успешного запуска. Локальные данные пользователей при этом не мигрируют и не удаляются, поскольку схема состояния остаётся `v1`.

## Архитектура

- Blazor WebAssembly и Microsoft Fluent UI Blazor.
- Изолированные ES modules для Web Serial, `localStorage` и скачивания.
- Версионированный `AppState` в `localStorage` под ключом `datamatrix-notepad.state.v1`.
- Потоковый C#-парсер отделяет произвольные serial chunks по префиксу и суффиксу.
- Чистые C#-сервисы отвечают за состояние заметок и экспортное имя.
- xUnit покрывает парсинг кадров, состояние, сканирование и экспорт.

Согласованные требования и ограничения находятся в [спецификации](docs/spec.md), а поэтапный статус — в [плане](tasks/plan.md).

## Ограничения и приватность

- Одновременно читается один выбранный порт.
- Диагностический лог не сохраняется и ограничен 500 записями.
- Приложение не содержит телеметрии, учётных записей и сетевой синхронизации.
- Данные сканера выводятся как текст и не интерпретируются как HTML.
- Разрешение Web Serial принадлежит браузеру и может потребовать повторного выбора порта.
