## 3. Браузер и интерфейс

Повторить отдельно в Chrome и Edge.

- [ ] Главная страница открывается без необработанных ошибок в Console.
- [ ] Страница настроек открывается без необработанных ошибок в Console.
- [ ] При ширине 1280 px основные действия и редактор видимы без горизонтальной прокрутки.
- [ ] При ширине 600 px основные действия складываются в одну колонку без горизонтальной прокрутки.
- [ ] Все поля имеют видимые подписи; Tab проходит элементы в логичном порядке.
- [ ] Focus indicator виден на ссылках, полях и кнопках.
- [ ] Skip-link появляется при первом нажатии Tab и переводит focus к содержимому.
- [ ] Escape закрывает диалог удаления.
- [ ] Tab и Shift+Tab остаются внутри открытого диалога.
- [ ] После отмены focus возвращается на «Удалить заметку».
- [ ] После удаления focus переходит к удалению следующей заметки либо к «Новая заметка».
- [ ] При отсутствии `navigator.serial` показано понятное сообщение; фиктивного подключения нет.
- [ ] Ошибки настройки, сохранения, подключения и скачивания показаны рядом с соответствующим действием.

## 4. Хранение и заметки

- [ ] Создать две заметки; после reload названия, тексты и активная заметка восстановились.
- [ ] Изменить поле и сразу закрыть/перезагрузить вкладку; последнее изменение сохранилось через `pagehide`.
- [ ] Пустое название показано в списке как «Без названия».
- [ ] Отмена удаления не меняет заметку.
- [ ] Подтверждение удаляет только выбранную заметку.
- [ ] После удаления активной заметки выбрана соседняя; после удаления последней показано пустое состояние.
- [ ] В сохранённом JSON есть VID/PID и параметры, но нет объекта `SerialPort`.

## 5. Web Serial и реальный сканер

- [ ] Chrome определяет Web Serial и открывает picker только после нажатия кнопки.
- [ ] Edge определяет Web Serial и открывает picker только после нажатия кнопки.
- [ ] Отмена picker показывает нейтральное сообщение и не повреждает заметки.
- [ ] Порт открывается с фактическими настройками сканера.
- [ ] Диагностический лог показывает псевдоним, VID/PID при наличии, сырые данные и завершённый код.
- [ ] CRLF отображается как `\r\n`.
- [ ] Код, разбитый между несколькими чтениями, добавляется один раз и полностью.
- [ ] Десять последовательных сканов дают ровно десять отдельных строк.
- [ ] Повтор одного кода добавляет дубликат отдельной строкой.
- [ ] Без активной заметки показано предупреждение; новая заметка не создаётся.
- [ ] Скан на странице настроек не меняет заметку.
- [ ] Переходы Settings → Home → Settings не создают дублирующихся обработчиков.
- [ ] Отключение USB показывает состояние отключения/ошибку без повреждения заметок.
- [ ] Повторное подключение работает.
- [ ] После reload ровно один подходящий разрешённый порт подключается повторно.
- [ ] При нуле или нескольких совпадениях приложение требует ручной picker.

## 6. Экспорт

- [ ] `Партия 00ЦБ-123456 от 25.07.2026` → `123456;25.07.2026.txt`.

- [ ] `От 25.07.2026` → `;25.07.2026.txt`.

- [ ] Повторные скачивания работают; в Console нет ошибок.
- [ ] Экспорт не меняет заметку, статус сохранения и serial-соединение.
