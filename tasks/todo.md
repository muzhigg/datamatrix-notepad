## T3. Один Web Serial-порт и диагностический лог

**Описание:** реализовать первый вертикальный срез Web Serial: проверка поддержки, системный выбор одного порта, подключение, streaming UTF-8 чтение, отключение и диагностический лог активного порта.

**Критерии приёмки:**

- [ ] Выбор порта вызывается только кнопкой; отмена, занятый порт и отсутствие API дают понятное состояние.
- [ ] JS-модуль читает один порт, декодирует byte chunks streaming-декодером и безопасно закрывает reader/port.
- [ ] Настройки показывают до 500 записей с временем, портом, видимыми `\r`, `\n`, `\t` и завершёнными кодами.

**Проверка:**

- [ ] Полные тесты и Release-сборка проходят.
- [ ] В Chrome/Edge вручную проверить поддержку, picker, connect/disconnect и отсутствие ошибок console.
- [ ] С реальным сканером проверить отображение тестового кода и `\r\n`; если устройства нет, пометить аппаратную проверку незавершённой.

**Зависимости:** T1, T2.

**Предполагаемые файлы:**
